# Should I Open Here?

Demo: [3 minute youtube video](https://youtu.be/AJ1KMwtbGWE)

AI-powered business location analyzer. Enter an address + business type → get a full report on nearby competitors, foot traffic patterns, and a scored recommendation on whether you should open there.

Reports are generated by Claude (Anthropic) and saved to Box as shareable files.


## Quickstart

### 1 — Backend

```bash
cd backend
python -m venv venv && source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env   # fill in your API keys (see Environment Variables below)

uvicorn main:app --reload --port 8001
# API  →  http://localhost:8001
# Docs →  http://localhost:8001/docs
```

By default both the scraper and the AI agent run in **mock mode** — no API keys are needed for a quick smoke-test. Set `USE_MOCK_SCRAPER=false` and `USE_MOCK_AGENT=false` in `.env` to switch to live data.

### 2 — Frontend

Open `frontend/index.html` directly in your browser — no build step or dev server is needed.

Make sure the `API_BASE` constant in the `<script>` block matches your backend port (default: `http://localhost:8001`).

### 3 — Standalone CLI agent

```bash
# Score a JSON file without starting the server:
python agent.py sample_input.json \
  --address "411 15th Ave E, Seattle, WA 98112" \
  --day Saturday --open 11:00 --close 23:00 \
  --search "vegan restaurant"

# Dry-run (no API call, prints signals JSON):
python agent.py --mock
```

## Data Flow

```
User (browser)
  │  POST /analyze { location, business_type, lat?, lng?,
  │                  day_of_week?, opening_time?, closing_time? }
  ▼
FastAPI (backend/main.py)
  │
  ├─① scrape_location()
  │     Real path  → Apify Google Maps actor  (competitor names, ratings,
  │                   hours, categories)
  │                → Apify Traffic actor per-hour  (Free Flow / Slow /
  │                   Moderate Congestion / Heavy Congestion counts)
  │                → geopy  (geocode address → lat/lng)
  │                → timezonefinder + pytz  (convert local hours → UTC)
  │     Mock path  → deterministic fake data seeded from location string
  │
  ├─② generate_report()
  │     scoring.py → compute_signals():
  │       • competitor_count, avg_rating, review_volume
  │       • foot_traffic classification (from hourly congestion ratios)
  │       • overlap_hours  (competitor hours vs. your opening hours)
  │       • market_saturation score
  │     Claude claude-sonnet-4-5 → structured markdown report
  │
  └─③ upload_report_to_box()
        Box SDK → upload .md file → generate shared link
  
  Response: { box_link, report_preview, location, business_type }
  │
  ▼
Frontend renders markdown report in-page + "Open in Box" button
```

## API Reference

### `POST /analyze`

**Request body:**
```json
{
  "location":      "411 15th Ave E, Seattle, WA 98112",
  "business_type": "vegan restaurant",
  "lat":           47.6237,
  "lng":           -122.3143,
  "day_of_week":   "Saturday",
  "opening_time":  "11:00",
  "closing_time":  "23:00"
}
```
`lat`, `lng`, `day_of_week`, `opening_time`, and `closing_time` are all optional.

**Response:**
```json
{
  "box_link":       "https://app.box.com/s/...",
  "report_preview": "# Location Analysis\n...",
  "location":       "411 15th Ave E, Seattle, WA 98112",
  "business_type":  "vegan restaurant"
}
```

### `GET /health`
Returns `{ "status": "ok" }`.

## Shared Data Contract

`schema.json` defines the JSON schema that all layers agree on. Read this file before making changes to the scraper or agent interfaces.

Key integration points:
- **Scraper → Backend**: `scraper_real.py` exposes `async scrape(location, business_type, lat, lng, opening_time, closing_time) → dict`. Set `USE_MOCK_SCRAPER=false` in `.env` to activate.
- **Agent → Backend**: `report_agent_real.py` exposes `async generate(scrape_data: dict) → str`. Set `USE_MOCK_AGENT=false` in `.env` to activate.
- **Backend → Frontend**: `POST /analyze` returns `{ box_link, report_preview }`.
